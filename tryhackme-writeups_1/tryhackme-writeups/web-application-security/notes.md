# Web Application Security

**Estado:** Completado (nivel easy)
**Plataforma:** TryHackMe

## Objetivo de la sala
Introducción a las aplicaciones web y sus problemas de seguridad más comunes.

## Conceptos clave aprendidos
- Cómo funciona una aplicación web a alto nivel (cliente-servidor, peticiones HTTP).
- Vulnerabilidades comunes: inyección, XSS, control de acceso roto (a nivel introductorio).
- Por qué la seguridad debe pensarse desde el diseño de la aplicación, no como parche posterior.

## Reflexión
Buena introducción antes de meterse en salas más técnicas de pentesting web (OWASP Top 10 y similares).
