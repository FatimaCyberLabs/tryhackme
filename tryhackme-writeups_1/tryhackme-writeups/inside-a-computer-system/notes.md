# Inside a Computer System

**Estado:** Completado (nivel easy)
**Plataforma:** TryHackMe

## Objetivo de la sala
Componentes básicos de un sistema informático.

## Conceptos clave aprendidos
- Hardware esencial: CPU, memoria RAM, almacenamiento, entrada/salida.
- Cómo interactúan el sistema operativo y el hardware a alto nivel.
- Conceptos base necesarios para entender rendimiento y monitorización de recursos.

## Reflexión
Sala de fundamentos "de toda la vida", útil como repaso si viene de fuera del mundo IT.
