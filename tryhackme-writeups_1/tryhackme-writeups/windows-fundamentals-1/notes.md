# Windows Fundamentals 1

**Estado:** Completado
**Plataforma:** TryHackMe

## Objetivo de la sala
Introducción al escritorio de Windows, el sistema de archivos NTFS, el Control de Cuentas de Usuario (UAC) y el Panel de Control.

## Conceptos clave aprendidos
- Estructura del sistema de archivos NTFS y organización de carpetas del sistema.
- Qué es UAC y por qué existe (control de permisos elevados).
- Navegación por el Panel de Control y configuración básica del sistema.
- Diferencias entre ediciones de Windows y sus casos de uso.

## Reflexión
Base para entender el entorno Windows antes de entrar en herramientas administrativas más avanzadas.
