# Windows Fundamentals 2

**Estado:** Completado
**Plataforma:** TryHackMe

## Objetivo de la sala
Profundizar en configuración del sistema, ajustes de UAC, monitorización de recursos y el Registro de Windows.

## Conceptos clave aprendidos
- Herramientas de configuración avanzada del sistema (System Configuration / msconfig).
- Monitor de recursos: CPU, memoria, disco, red en tiempo real.
- Introducción al Registro de Windows (`regedit`) y su papel en la configuración del sistema.
- Ajustes más finos de UAC y niveles de notificación.

## Reflexión
Conecta directamente con seguridad: entender el registro y la configuración del sistema es clave para detectar cambios sospechosos más adelante.
