# Linux Fundamentals Part 1

**Estado:** Completado
**Plataforma:** TryHackMe

## Objetivo de la sala
Primeros pasos en un terminal Linux interactivo: comandos esenciales para moverse por el sistema de archivos y ejecutar tareas básicas.

## Conceptos clave aprendidos
- Navegación por el sistema de archivos: `pwd`, `cd`, `ls`, estructura de directorios en Linux (`/home`, `/etc`, `/var`, etc.).
- Comandos básicos de gestión de archivos: `cat`, `cp`, `mv`, `rm`, `mkdir`.
- Uso de `man` para consultar documentación de comandos.
- Diferencia entre rutas absolutas y relativas.

## Reflexión
Primer contacto real con terminal en lugar de solo lectura teórica. Sienta las bases de shell que se usan en prácticamente todo lo demás (Nmap, Wireshark, HTB, etc.).
