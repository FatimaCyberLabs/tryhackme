# Defensive Security Intro

**Estado:** Completado
**Plataforma:** TryHackMe

## Objetivo de la sala
Introducción a la seguridad defensiva a través de un escenario simulado: proteger "FakeBank" durante un ataque en curso.

## Conceptos clave aprendidos
- Rol de un analista SOC / blue team durante un incidente activo.
- Conceptos de detección, contención y respuesta ante un ataque.
- Diferencias prácticas entre el enfoque ofensivo (atacar) y el defensivo (proteger/responder).

## Reflexión
Sala clave para comparar de forma práctica ofensiva vs. defensiva y orientar hacia qué especialidad tirar.
